# ARS RMS design

Staff use this interface in normally lit reception offices, nursing stations and counselling rooms, so the application uses light surfaces and readable dark text.

System typography, navy navigation, white content, light grey background, muted green success states and restrained amber warnings. Bootstrap 5 controls and tables; 4px corners; no animation or decorative shadows. Fixed desktop sidebar and mobile offcanvas. Page headings at 24px; labels at 14px. Permissions, audit history and account states must remain legible without relying on colour.
